# واجبات ويب 1

أنا الطالبة **إسراء معمر** - نظم معلومات، جامعة الأقصى.  
هذا المستودع فيه حل أنشطة مادة تصميم وإدارة مواقع الإنترنت 1:

- **المهمة 1:** صفحة سيرة ذاتية بسيطة (HTML فقط).
- **المهمة 2:** صفحة فورم لتسجيل مستخدم (Form).
- **المهمة 3:** صفحة مقال لمدونة (Semantic HTML).
- **المهمة 4:** السيرة الذاتية مع تنسيقات CSS.
- **المهمة 5:** صفحة هبوط بسيطة (Landing Page).
