# واجبات مادة تصميم وإدارة مواقع الإنترنت 1

أهلاً بكم، أنا **إسراء عمر معمر**، طالبة سنة أولى في جامعة الأقصى - تخصص نظم معلومات، ومصممة جرافيك.

أنشأت هذا المستودع لأرفع فيه تكليفات وأنشطة مساق الويب 1 المطلوبة منا في الجامعة، وقسمت كل نشاط في مجلد مستقل عشان يكون الكود مرتب وسهل التصفح.

---

### محتويات المجلدات:

- **المهمة 1 - سيرة ذاتية:**  
  صفحة سيرة ذاتية بسيطة كتبتها بلغة HTML فقط بدون تنسيقات، فيها معلوماتي الشخصية والمهارات والتعليم والخبرات ومعلومات التواصل.

- **المهمة 2 - نموذج تسجيل:**  
  نموذج تسجيل مستخدم يحتوي على حقول مختلفة مثل الاسم والإيميل وكلمة المرور وتاريخ الميلاد واختيار المدينة والاهتمامات، مع شروط التحقق.

- **المهمة 3 - مقالة مدونة:**  
  صفحة مقال عن أهمية التصميم البسيط في صفحات الويب، كتبتها باستخدام وسوم HTML الدلالية مع صورة وفيديو تعليمي وشريط جانبي.

- **المهمة 4 - تنسيق السيرة الذاتية:**  
  تطبيق تنسيقات CSS على السيرة الذاتية لتظهر بشكل بطاقة داكنة ومرتبة مع تنسيق المهارات والجداول والمشاريع.

- **المهمة 5 - صفحة هبوط:**  
  صفحة هبوط متجاوبة نسقتها بملف CSS خارجي بالاعتماد على Flexbox و Grid.
